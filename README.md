# Maarten's Birthday 2026

AI heeft er voor gezorgd dat we terug kunnen naar een tijdperk voordat AI bestond. Voordat Enshittification een ding was. Toen alles nog simpel en puur was.

Dit pareltje van een OS heeft de tijd goed doorstaan, en kan zelfs nu nog mee. Nu is het een soort tijdmachine, met een vleugje nostalgie. Kan je terug naar het verleden, en kijken naar het heden? Of kijk je liever naar een gebeurtenis van zo'n 3 weken geleden? Heel veel plezier!

## Ontwikkelen

```bash
npm install
npm run dev
```
